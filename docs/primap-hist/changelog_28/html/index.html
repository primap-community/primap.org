Overview

This analysis shows per country changes from PRIMAP-hist PRIMAP-hist_v2.7_final_nr to PRIMAP-hist PRIMAP-hist_v2.8_final_nr on a per country, gas, and sector level. It aims to give quick overview over the countries with the highest changes and presents details on thesectors and gases with the highest changes. Where changes are high and / or impact cumulative emissions we give explanations for the change.

In the following we give a short overview over the most importantchanges in input data and processing which will help to understand per country, gas, and sector changes.For general information on the dataset please consult the data description document.

Overview over changes from v2.7_final to v2.8_final

The v2.8 release updates country reported and third party data sources. New and updated country reported input data sources are:

  • UNFCCC Common Reporting Table (CRT) data from Biannial Transparency Reports (BTRs) for non-AnnexI countries
  • UNFCCC CRT data from National Inventory Submissions for AnnexI countries
  • Data from BTR, Biannial Update Report (BUR), and National Communication (NC) pdf files (or the National Inventory Report (NIR) or National Inventory Document (NID) files submitted to the UNFCCC with the BTRs, BURs or NCs)
  • Data from national inventories not submitted to the UNFCCC
  • Data from third party country specific inventories (for cases where countries don’t provide emissions inventories)

Updated third party data sources are

  • Emissions Database for Global Atmospheric Research (EDGAR) 2025 release
  • FAOSTAT 2025 release
  • EI Statistical Review of World Energy 2026
  • Global CO2 from Cement Production version 260526

Per country changes are listed in the following section. For further details we refer to the country pages.

Important note on the “TP” scenario

The TP scenario is no longer actively maintained as a PRIMAP-hist scenario with manual checks of the resulting data and description of the changes. Time-series are only provided for comparison with the country reported data priority scenario (CR). Do not use the TP scenario data without proper checks. There are no commercial licenses for the TP time-series available. If you are interested in a commercially usable emissions dataset which prioritizes third party data please contact commercial-support@johannes-guetschow.de.

  • We have added the following special treatments:
    • Jordan: We extrapolate UNFCCC dat in 1.B.2 for N2O until 1988 to avoid scaling artifacts with EDGAR data.
    • Guyana: Extending UNFCCC data with EI gives low emissions for 1.A. We use linear extrapolation of UNFCCC data for a year (2023).
    • Algeria: Using a linear trend for 2024 livestock CH4 emissions gives low emissions because of an emissions drop in UNFCCC data due to a revision of national statistics in 2022. We avoid this using linear extrapolation of EDGAR data for a year (2024).
    • Lebanon: Scaling EI to UNFCCC for CO2 in 1.A gives high emissions, because the EI downscaling uses average emissions over 10 years which do not fully account for the recent emissions drop. We use constant extrapolation of UNFCCC data for a year (2023).
    • Saudi Arabia: Scaling EI to UNFCCC for CO2 in 1.B.2 gives high emissions. We add UNFCCC data to EI for 2010 and 2012 to fix control the harmonization factor.
    • Bahrain: We remove EI CO2 data in 1.B.2 because it is not continuous and hard to harmonize to UNFCCC data.
    • Brunei Darussalam: Scaling EDGAR N2O data in category 4 to UNFCCC data gives huge emissions. We use linear extrapolation of UNFCCC data for two years (1998, 1999) to avoid this.
    • Ukraine, Italy: Very high 2024-2025 growth rate for 1.B.2 in the EI data gives very high emissions for 2025 when harmonized to UNFCCC data. We remove the 2025 value, so numerical methods are used.
    • Eswatini: CO2 data in 2.A are missing for 2018 and later in UNFCCC data but should be zero because the last cement factory closed in 2017. We set the data to zero to avoid extrapolation with non-zero data.
    • India: EDGAR 2025 data for 2.B, N2O have a discontinuity between 2009 and 2010. To match the pre-2010 data better to UNFCCC data for 2010 and later we extrapolate the CRT data to 2009 to match to the pre-2000 EDGAR time-series.
    • Venezuela: Using a linear trend for 2025 fugitive CH4 emissions in 1.B.2 gives low emissions because of an emissions peak in UNFCCC data for 2020 and 2021. We use linear extrapolation of EDGAR data for a year (2025) instead.

  • Bugs affecting individual countries are listed on the country pages.

Known problems (v2.8)

This listing only contains issues that affect several countries. For individual country issues see also the country pages.

  • For some countries scaling of historical CO2 emissions especially for 1.B.2 remains problematic. (issue #34)
  • Process emissions from lime production (2.A.2) are currently not included in the third party priority (TP) scenario, as we use Andrew cement data as a proxy for sector 2.A. To include lime process emissions sub-sector resolution of 2.A would have to be introduced. (issue #38)
  • EDGAR data for N2O, 1.B.1 is very limited for some countries, thus extrapolation generates most of the data for those countries. (issue #42)
  • For some countries some timeseries start later than 1750, so long range historical data (CEDS etc.) are (partly) missing. This issues has been fixed for most cases, but a few remain. (see issue #56)
  • For problems that were found after the release of the dataset, please consult the issue tracker github.com/JGuetschow/PRIMAP-hist. If you encounter a problem please add an issue or contact the authors directly.

Noteworthy changes (v2.8)

Here we only list changes affecting all countries, country groups or several countries. For detailed per country changes please consult the country pages. * For the “country reported priority” time series we have new data covering all sectors for many countries. For AnnexI countries the changes are limited for most countries. Many countries have changes in the LULUCF sector and emissions from managed soils. Further common sources of data changes are f-gases and N2O emissions from fossil fuel combustion, namely diesel oil use. Some non-AnnexI countries with new country reported data have high changes which affect all years, gases and sectors. * EDGAR data have been updated for several sectors and gases. This affects the CR scenario for countries where country reported data does not cover recent years or not all sectors and gases. * FAOSTAT data have been updated for all years for some countries. Other have corrections for the latest years. This affects the CR scenario for countries where country reported data does not cover recent years or not all sectors and gases. * Andrew cement data have been updated for recent years for many countries which also affects the CR scenario. * The updated EI data includes corrected emissions for the latest years for many countries, especially the countries only included in regional groups in the EI data. This mostly affects 2024 emissions.
