Notes on data changes

Here we list notes explaining important emissions changes for the country.

  • No new country reported data has been added.
  • The only change for CR and TP time-series is a reduction in energy CO2 originating from the new EI data. As EI data is only used post 2020 in the TP scenario and post 2022 in the CR scenario the change only affects the latest years.
