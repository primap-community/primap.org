Notes on data changes

Here we list notes explaining important emissions changes for the country.

  • CRT data from BTR1 has been added allowing the use of country reported data for the first time. Consequently this introduces completely new time-series as the CR time-series was identical to the TP time-series in PRIMAP-hist v2.6.1 and earlier versions.
    • The changes are much higher for recent years as especially recent emissions differ between country reported and third party data especially CO2 in 2.A.
    • Many of the differences that affect the full time-series are for sectors and gases which have high uncertainty, such as agriculture, waste, and CH4 from energy.
  • The TP time series has only changed for energy CO2 because of the new EI data and waste CO2 which has been added from country reported data.
